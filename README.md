# HIMC

환자의 위치, NGUMLD 위험도, 질환 유형별 병원 기본점수를 결합해 수도권 26개 병원을 비교하는 서버리스 공간 복지 대시보드입니다.

- 공개 사이트: <https://leejuhan-1214.github.io/HIMC/>
- 기술 구성: HTML5, CSS3, Vanilla JavaScript, Leaflet.js, Turf.js, PapaParse

## 구현 기능

- 서울·경기·인천 26개 병원 지도 표시
- 급성·만성·암 질환별 기본점수 분기
- 6개 NGUMLD 입력을 이용한 환자 위험도 계산
- 환자 위치와 병원 사이의 지표면 직선거리 계산
- 기본점수에서 거리 페널티를 차감한 Top 5 추천
- 기본점수·거리·페널티·최종점수 계산 상세 표시
- 병원별 고정 색상을 적용한 최근접 병원 보로노이 권역
- 지도 클릭 및 브라우저 현재 위치를 이용한 환자 위치 변경
- CSV 점수 갱신, 행별 검증, 중복·미매칭·범위 오류 보고
- 샘플 CSV 다운로드
- 병원·보로노이·추천 연결선 레이어 전환
- 모바일·태블릿 반응형 레이아웃
- 외부 지도·라이브러리 로딩 실패 안내
- 의료 안전 안내와 데이터 출처 링크

## NGUMLD 환자 위험도

각 입력값은 0~100 범위입니다.

```text
R = 0.15N + 0.05G + 0.25U + 0.25M + 0.15L + 0.15D
```

- `N`: 나이 위험도
- `G`: 성별·질환 연관도
- `U`: 긴급도
- `M`: 동반질환
- `L`: 예상 입원기간 부담
- `D`: 사회적 결핍

가중치 합은 1이며 모든 입력이 50이면 위험도 `R`도 50입니다.

## 동적 병원 점수

```text
거리 페널티 = 직선거리(km) × ((100 - R) / 50)
최종 점수 = 선택 질환의 병원 기본점수 - 거리 페널티
```

현재 모델은 위험도가 높을수록 거리 페널티를 줄이고 질환별 기본점수를 더 크게 반영합니다. 거리는 도로 이동시간이 아닌 Turf.js의 지표면 직선거리입니다.

## CSV 데이터

저장소의 `sample-hospital-scores.csv`를 내려받아 편집할 수 있습니다.

```csv
병원ID,병원명,급성,만성,암
H001,서울대학교병원,98,95,99
H004,서울아산병원,97,96,98
```

검증 규칙:

- `병원ID`/`hospital_id` 또는 `병원명`/`병원`으로 정확히 매칭
- 질환 점수는 0~100 범위의 숫자만 허용
- 동일 병원 중복 행 제외
- 알 수 없는 병원, 빈 점수 행, 파싱 오류를 상세 보고
- CSV는 브라우저 안에서만 처리되며 서버로 전송되지 않음

## 데이터 출처와 제한

내장된 26개 병원 점수는 기능 시연을 위한 기본값이며 공식 의료기관 평가가 아닙니다. 실제 활용 전에는 검증된 평가자료로 교체해야 합니다.

- [건강보험심사평가원 병원평가정보](https://www.hira.or.kr/ra/eval/getDiagEvlList.do?pgmid=HIRAA030004000000)
- [건강보험심사평가원 병원정보서비스 API](https://www.data.go.kr/data/15001698/openapi.do)

보로노이 구역은 가장 가까운 병원에 따른 기하학적 구분이며 질환·위험도 기반 추천권역이나 실제 진료권을 의미하지 않습니다.

## 의료 안전

이 프로젝트는 연구·시연용이며 의료 조언, 진단, 응급 이송 또는 실제 병원 선택을 대신하지 않습니다. 응급 상황에서는 119와 의료진의 안내를 우선해야 합니다.

## 로컬 실행

별도 빌드 과정이 없습니다.

```bash
python -m http.server 8000
```

실행 후 <http://localhost:8000>으로 접속합니다. 지도와 분석 라이브러리는 외부 CDN 및 지도 타일 서비스를 사용하므로 인터넷 연결이 필요합니다.

`main` 브랜치에 변경사항이 푸시되면 `.github/workflows/deploy-pages.yml`이 GitHub Pages에 자동 배포합니다.
