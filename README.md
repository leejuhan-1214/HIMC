# HIMC

대한민국 5개 지역의 냉난방 환경피해와 DAC(직접공기포집) 설치 우선순위를 살펴보는 정적 웹 대시보드입니다.

## 주요 기능

- 서울·인천·부산·울산·강원의 CHI와 DPS 비교
- 전국 600개 보로노이 구역의 지표별 농도 표시
- CHI/DPS 기준 전환
- 1~10개 DAC 거점 후보의 탐욕적 최대커버 계산
- 지도 확대·축소, 드래그 이동, 더블클릭 초기화
- 지역별 핵심 탄소 저감 처방 제시

## 지표 계산

### CHI — 냉난방 환경피해지수

```text
CHI = 0.30P + 0.25B + 0.20E + 0.15R + 0.10F
```

- `P`: 인구 관련 입력
- `B`: 건물 관련 입력
- `E`: 에너지 관련 입력
- `R`: 냉매 관련 입력
- `F`: 전력 배출계수 관련 입력

### DPS — DAC 설치 우선순위 점수

```text
DPS = 0.35CHI + 0.20U + 0.20RE + 0.15T + 0.10EF
```

- `U`: 산업·CO₂ 활용성
- `RE`: 재생에너지 여건
- `T`: CO₂ 운송 접근성
- `EF`: 전자연료 잠재력

울산 DPS는 포함된 입력값과 위 수식으로 다시 계산한 `88`을 사용합니다. 원 참고값 `92`는 모든 입력을 0~100으로 둘 때 재현되지 않습니다.

## 실행

별도의 설치나 빌드 과정이 없습니다. `index.html`을 직접 열거나 로컬 웹 서버로 실행할 수 있습니다.

```bash
python -m http.server 8000
```

실행 후 `http://localhost:8000`으로 접속합니다. 툴팁과 아이콘 라이브러리는 CDN에서 불러오므로 해당 기능에는 인터넷 연결이 필요합니다.

## 파일 구성

- `index.html`: 스타일, 지도 데이터, 계산 로직을 모두 포함한 단일 페이지 앱
- `README.md`: 프로젝트 설명과 지표 정의

## 해석 시 주의사항

- 지역 점수와 600개 보로노이 구역은 제공된 입력을 바탕으로 한 시각화·시나리오 모델입니다.
- DAC 후보 선택은 고정 반경 안에서 아직 커버되지 않은 지표 점수의 합을 가장 크게 늘리는 지점을 순차 선택하는 탐욕 알고리즘입니다. 전역 최적해를 보장하지 않습니다.
- 행정경계는 KOSTAT 2013 기반 `southkorea-maps` 형상을 사용합니다.
- 실제 입지 결정에는 최신 행정경계, 토지 이용, 비용, 전력망, 수자원, 규제, 주민 수용성 등 추가 검토가 필요합니다.
