# HIMC

수도권 주요 병원을 질환 유형, 환자 중증도, 취약성, 환자 위치에 따라 비교하는 공간 복지 대시보드입니다.

## 주요 기능

- 서울·경기·인천 26개 병원 지도 표시
- 급성·만성·암 질환별 병원 기본 평가 점수 적용
- 생체징후, 의식 수준, 통증, 기저질환을 반영한 중증도 계산
- 지도에서 선택한 환자 위치와 병원 간 직선거리 계산
- 병원 평가 점수에서 거리 페널티를 차감한 상위 5개 병원 표시
- 병원별 보로노이 영향권, 병원 위치 레이어 전환
- CSV 파일을 이용한 질환별 병원 평가 점수 갱신

## 점수 계산

```text
중증도 = 생체징후 × 0.40
       + 의식 수준 × 0.35
       + 통증 강도 × 0.15
       + 환자 취약성 × 0.10

거리 페널티 = 직선거리(km) × ((100 - 중증도) / 50)

최종 점수 = 선택 질환의 병원 평가 점수 - 거리 페널티
```

중증도가 높을수록 거리 페널티가 작아져 병원의 질환별 평가 점수가 더 크게 반영됩니다.

## CSV 데이터 형식

`병원명` 또는 `병원` 열과 질환 점수 열을 사용합니다.

```csv
병원명,급성,만성,암
서울대학교병원,98,95,99
서울아산병원,97,96,98
```

점수 열은 `급성점수`, `만성점수`, `암점수`라는 이름도 지원합니다. CSV는 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.

## 실행

별도 빌드 과정이 없는 정적 웹페이지입니다.

```bash
python -m http.server 8000
```

실행 후 `http://localhost:8000`으로 접속합니다. 지도와 분석 라이브러리를 외부 서비스에서 불러오므로 인터넷 연결이 필요합니다.

## 해석 시 주의사항

- 포함된 병원 평가 점수는 대시보드 시연용 기본값이며 공식 의료기관 평가가 아닙니다.
- 거리는 도로 이동시간이 아닌 두 지점 사이의 직선거리입니다.
- 보로노이 구역은 가장 가까운 병원에 따른 기하학적 구분일 뿐 실제 진료권이나 응급의료 권역이 아닙니다.
- 이 대시보드는 의료 조언, 진단, 응급 이송 또는 실제 병원 선택을 대신하지 않습니다. 응급 상황에서는 119 및 의료진의 안내를 우선해야 합니다.
